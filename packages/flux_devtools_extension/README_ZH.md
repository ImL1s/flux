# Flux DevTools 擴充功能 (Flux DevTools Extension)

[English Documentation](README.md)

Flux 程式語言的官方 Flutter DevTools 擴充功能。

此工具整合在 Flutter DevTools 中，提供針對 Flux 虛擬機 (VM) 的深度檢查、性能分析和狀態追蹤功能。

## 入門指南

要在開發當中使用此擴充功能：

1. 執行您的 Flutter 應用程式。
2. 開啟 Flutter DevTools。
3. 在選項卡中找到 "Flux" 標籤。

## 特性

- **VM 狀態檢查**：即時查看虛擬機內的變數、物件和閉包。
- **組件樹 (Widget Tree)**：檢查 Flux 指令碼生成的組件樹結構。
- **性能分析**：追蹤指令碼執行時間，找出瓶頸。
- **狀態歷史**：查看 Flux 狀態 (State) 的變化歷史。
